Pitch loop SET_PID_FB

P front applies when pitch is above the trimmed target (forward lean); P back applies below it. Both use the P boost settings. I and D are shared. Reboot restores both P gains to 0.04.

Large-angle D boost

Boost adds damping as angle error grows in either direction. 0 = off; 1 approaches 2× base D at large angles. Angle (°) is where half the extra boost applies. Base D is unchanged at zero error. Reboot restores Boost 0 and Angle 5°.

Near-zero P boost

Boost sets extra P response (0 = off). Width sets the angle-error range around the balance target: smaller = tighter and stronger near zero; larger = broader and gentler. The transition is smooth, not a cutoff. Changes apply live; reboot restores Boost 0.65° and Width 0.5°. Active values appear below.

Values are saved in this browser and sent when you change them.

Velocity loop SET_VEL

Velocity sensor fusion

Enter measured wheel diameter (50–500 mm). Diameter 0 or τ 0 = wheel-only. Larger τ gives acceleration more influence; 0.2 s is the starting value. Missing wheel feedback still returns the target toward neutral. Reboot restores diameter 160 mm and τ 0.2 s. Reapply any custom values after reconnecting.

Wheel RPM → target lean (deg per RPM, capped at 3°). Both 0 = off. Resets to 0 on robot reboot. Check wheel L/R move when you push the robot first. Start vkp 0.05, then vki 0.02. Runs away instead of stopping = flip sign.

Trim SET_TRIM / ZERO_IMU

Zero IMU makes the current angle the balance point. Saved to flash.
